# ARCH 360 Tour

A web-based 360° virtual walk-through of the project — 23 panoramic locations across the
outdoor area, turf, and the ground, first, second and third floors.

**Live site:** https://puvaneshram.github.io/arch-360-tour/

- Click or tap the circles on the floor to walk to the next location (like a street-view walk-through).
- Use the dropdown at the top right to jump to any location.
- Works on desktop, phones and Meta Quest 3 (press the VR goggles icon in the Quest Browser).

Built with [A-Frame](https://aframe.io/). Panoramas are 3840×1920 equirectangular renders made in Blender.
